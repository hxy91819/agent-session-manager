## 阈值决定

阶段 C 保持方案中的报告阈值不变：函数 50 行、30 条语句、认知复杂度 15、
圈复杂度 10、文件 400 行、clone 50 tokens。它们大致覆盖生产分布的上尾，且
当前数据没有证明需要在报告期开始前改动定义或 series。

阶段 D 的 hard 阈值仍只是候选值，不在本批次启用。特别是 600 行文件阈值低于
历史生产文件 P90（667），但规则只约束新文件和存量超限文件继续增长；阶段 C
需要重点验证其误报率。80-token clone 阈值接近历史 clone P50，也应在报告期记录
触发率后再决定是否启用。

本批次未修改产品代码、未清理任何存量超限项，也未把 code-health 接入阻断 CI。
